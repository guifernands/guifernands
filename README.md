## 🚀 Projeto em destaque

### Clone KaBuM — Aplicação Web de E-commerce

Aplicação web completa de e-commerce desenvolvida durante um teste técnico prático de 30 dias em ambiente real de desenvolvimento, com orientação e feedbacks de profissionais experientes.

O projeto conta com:

- Cadastro e login de usuários
- Catálogo e detalhes de produtos
- Sistema de favoritos
- Carrinho integrado com back-end
- Cupons, checkout e pedidos
- Painel administrativo
- Integração com banco de dados PostgreSQL/Neon
- Organização em camadas, Clean Code, SOLID e conceitos de DDD

**Stack:** React, JavaScript, Vite, Tailwind CSS, Zustand, React Router, React Hook Form, Zod, C#, ASP.NET Core Web API, Entity Framework Core e PostgreSQL/Neon.
